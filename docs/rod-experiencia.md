# ROD Studio: experiência visual e cérebro 3D

Pedido: aproximar a interface das referências da marca ROD e tornar a relação entre projeto, escolhas e processos cerebrais fácil de explorar.

Decisão: manter HTML/Three.js e todos os módulos existentes. Criar uma tela principal Projeto, navegação lateral por tarefas, cérebro grande e seis processos selecionáveis com explicação, aplicação e próximo passo. Usar o logo fornecido sem redesenhar. Preto, branco quente e lettering de marcador em títulos; cores restritas à identificação dos processos. O modelo é anatômico aproximado, ilustrativo, sem porcentagens de ativação.

Fluxo: Novo projeto → material/ideia → intenção/público → objetivo/barreiras → salvar briefing. A análise depende do Claude ou de dados importados. Tela de exemplo continua claramente identificada. Fora do Claude, briefings locais persistem neste navegador e podem ser exportados.

Verificação: troca de processos, seleção de regiões, controles 3D, teclado, fluxo guiado, persistência local, todas as abas existentes e layout de 390px. Publicar código no GitHub privado; só declarar atualização do Artifact com acesso e publicação confirmados.
